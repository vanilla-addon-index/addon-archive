# Voice Reference Samples

Each folder = one voice profile. Drop **4-6 recordings of ~15 seconds each** per folder.

More clips with emotional variety = better cloning. Mix moods: calm exposition, 
urgency/commands, warmth/gratitude, anger/threats, whispering/secrecy, humor/sarcasm.

**Format**: `.wav`, clear speech, minimal background noise.

## Tips for Good Samples
- **Variety > quantity** — 4 clips with different emotions beats 6 clips of the same tone
- Think about the character: a Tauren elder speaks differently than a Goblin merchant
- Accents matter: Trolls have a Jamaican-ish accent in WoW, Dwarves are Scottish-ish
- For creatures like murlocs or wisps, lean into fantasy — it doesn't need to be "normal speech"
- Clean audio preferred, but character > perfection
