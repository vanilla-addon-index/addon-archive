# Kui Name Plates for OctoWoW

Compatibility build of Kui Nameplates for **OctoWoW**.

UPDATE - if you use ShaguTweaks you must turn off conflicting settings. Open the advanced options in ShaguTweaks and disable both nameplate scale and nameplate class colors."

FuBar_KuiNameplates is not needed but an included extra.


## Included AddOns
- `Kui_Nameplates`
- `Kui_Nameplates_Auras`
- `Kui_Media`
- `FuBar_KuiNameplates`


## Installation
1. Download the zip file in this repository.
2. Extract the included addon folders into your `Interface/AddOns/` directory.
3. Restart the game or reload the UI.

## Notes
- This package is intended for the OctoWoW client environment.

Use /kuinameplates or /knp to open options.
Click V to show enemy nameplates.
Click CTRL+V to show nameplates for all NPCs and players (enemies and allies).
Click Shift+V to show only friendly NPCs/players.
