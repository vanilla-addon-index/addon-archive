SexyMap OctoWoW Compatibility Package

Why this package exists:
- SexyMap v12.x targets modern WoW Classic clients and uses APIs not available in OctoWoW.
- This package swaps in a 1.12-compatible backport implementation so the addon can load on OctoWoW.

Features added in this package:
- Diablo by Zork preset (now the default)
- Faded Square by Renaitre preset
- Space by Ruka preset
- Clouds by koccs preset
- Rogue preset
- Electric preset
- New shapes: Large Circle, Route66, Deathsky, VFX Border
- All TGA textures converted to BLP (DXT3) format for classic WoW 1.12.x compatibility
- FPS counter removed

Install:
- The folder name must stay exactly the same and be named "SexyMap"
- Copy the SexyMap folder to Interface/AddOns/

Slash commands:
- /sm
- /sexymap
- /cm
