## I Want It All
This is yet another addon to rotate all your resource tracking abilities with a single button.

Type `/iwia` to display the list of available commands and tracking abilities.

Type `/iwia next` to switch to the next enabled tracking ability, or bind it in the "Key Bindings" menu.

### Supported Tracking Abilities
- ![](https://octowow.st/db/images/icons/small/inv_misc_flower_02.png) **Find Herbs** &rarr; `/iwia herbs on|off`
- ![](https://octowow.st/db/images/icons/small/spell_nature_earthquake.png) **Find Minerals** &rarr; `/iwia ores on|off`
- ![](https://octowow.st/db/images/icons/small/inv_tradeskillitem_03.png) **Find Trees** &rarr; `/iwia trees on|off`
- ![](https://octowow.st/db/images/icons/small/inv_misc_fish_28.png) **Find Fish** &rarr; `/iwia fish on|off`
- ![](https://octowow.st/db/images/icons/small/racial_dwarf_findtreasure.png) **Find Treasure** &rarr; `/iwia chests on|off`
