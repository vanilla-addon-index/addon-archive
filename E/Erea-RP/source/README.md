# E'rea RP Addons

A roleplay addon suite for [Turtle WoW](https://turtle-wow.org) (WoW 1.12) that lets Game Masters create and distribute interactive RP items to players.

📖 **[Full documentation](https://nice-hill-04f3e2003.2.azurestaticapps.net/)**

---

## Addons

| Addon | For | Description |
|-------|-----|-------------|
| **erea-rp-common** | Everyone | Shared libraries required by the other two addons |
| **erea-rp-player** | Players | RP bag inventory, item usage, and cinematic display |
| **erea-rp-master** | Game Masters | Item authoring, distribution, and player monitoring |

---

## Installation

Place all three addon folders in `TurtleWoW/Interface/AddOns/`.

- Enable **erea-rp-common** and **erea-rp-player** for all player accounts.
- Enable **erea-rp-master** on the character select screen for GM accounts only (disabled by default).

---

## Features

- **Item editor** — Create custom RP items with icons, tooltips, and readable content
- **Action system** — Chain actions (cinematics, inventory changes, text input, charge consumption)
- **Cinematic engine** — Full-screen dialogue sequences with speaker portraits and animations
- **Player monitor** — Real-time tracking of player sync status, locations, and inventories
- **Commit & sync workflow** — Draft-to-publish versioning for safe item distribution
- **Scripts library** — Embedded Lua scripting for dynamic content
